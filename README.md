
# Beam Deflection Toolkit

A Python project that calculates maximum deflection for five types of beams under different spans and loads.

## Files
- `beam.py`: Beam deflection functions
- `main.py`: Main calculation logic
- `config.json`: Input parameters
- `Output.csv`: Generated results

## Requirements
- Python 3
- No external packages required if using only Python standard libraries

## How to Run
1. Clone or download this repository.
2. Check the input values in `config.json`.
3. Run:

   python main.py

4. View the calculated results in `Output.csv`.
